## Introduction
This lab demonstrates the use of JavaScript
for client-side scripting and interactive
webpage development.

## Question 1 - Interactive Text Changer
Changes the paragraph message when the
user clicks the Change Message button.

Concepts:
- DOM selection
- JavaScript functions
- Event listeners

## Question 2 - Smart Number Validator
Accepts user input and checks whether the
number is lower than, higher than or equal
to 10.

Concepts:
- Functions
- If...else if...else
- Input validation
- Number conversion

## Question 3 - Dynamic Number Generator
Generates an ordered list containing
numbers 1 to 5 when the user clicks Generate.

Concepts:
- For loop
- document.createElement()
- textContent
- appendChild()

## Instructions to Run
1. Open the Q1, Q2 or Q3 folder.
2. Open index.html using a web browser.
3. Test the respective buttons and functions.
